# VantreLingo v0.1 — 验收要求

只有 P0 全部通过，才能认为 v0.1 核心完成。

## P0-01 中文首次翻译

前置：无最近外语记忆。

操作：

1. 选中中文。
2. 触发写作翻译。

预期：

- 源语言识别为中文；
- 目标默认为英语；
- 审查模式首次默认开启。

## P0-02 最近外语记忆

操作：

1. 选中日文，阅读翻译成中文。
2. 再选中中文，触发写作翻译。

预期：

- 第二次目标为日文；
- 最近外语为日文；
- “中文”不会覆盖最近外语。

再用德文重复，目标应变为德文。

## P0-03 失败不更新语言记忆

操作：

1. 当前最近外语为日文。
2. 手动选择中文 → 法文。
3. 模拟 Provider 超时。

预期：

- 最近外语仍为日文；
- 不写回原文。

## P0-04 迟到请求隔离

操作：

1. 请求 A 开始。
2. 立即触发请求 B。
3. 让 B 先完成、A 后完成。

预期：

A 不得：

- 覆盖 B 的显示；
- 覆盖剪贴板；
- 写回；
- 更新最近语言。

## P0-05 阅读模式只读

`Alt+D` 对任何支持控件执行。

预期：

- 不修改原文；
- 不触发写回；
- 不因当前写作模式是“快速”而改变。

## P0-06 快速模式焦点变化

操作：

1. 在编辑器 A 选中文本并触发快速翻译。
2. 等待期间切换到聊天窗口 B。
3. LLM 返回。

预期：

- A/B 都不被错误覆盖；
- 快速写回被阻止；
- 原文保持；
- 不强制抢焦点回 A。

## P0-07 快速模式原文变化

操作：

1. 触发快速翻译。
2. 返回前修改原选区。

预期：

- 不覆盖已修改内容；
- 结果仅允许后续人工查看/复制。

## P0-08 不写流式半成品

Provider 使用 streaming。

预期：

- UI 可选择显示流式预览；
- 原应用在结束前不发生任何文字修改；
- 只在完整结果校验通过后一次写回。

## P0-09 不使用全选兜底

对不支持可靠 selection range 的控件执行快速模式。

预期：

- 不发送 Ctrl+A；
- 不覆盖整个输入框；
- 降级为审查/复制。

## P0-10 剪贴板保护

操作：

1. 触发需要兼容复制的选区读取。
2. 等待期间用户复制新的内容。
3. 翻译完成。

预期：

- 用户新剪贴板内容不得被旧内容覆盖。

## P0-11 风格冲突

尝试：

- 正式文件 + 幽默风趣；
- 严格忠实 + 大幅压缩；
- 幽默 + 刻板直译。

预期：

- 本地配置层直接阻止；
- 不把冲突配置发给模型后“看模型怎么处理”。

## P0-12 自定义 Prompt 快速授权

操作：

1. 新建自由提示词。
2. 尝试快速模式。

预期：默认禁止快速。

用户明确授权后允许。

再次编辑 Prompt 后：

预期：授权自动失效。

## P0-13 正式文件数字保护

原文包含：

- 5,000 pcs；
- USD 0.85；
- 30% deposit；
- 230 × 70 × 40 mm；
- 2026-12-10。

模拟 LLM 漏掉或改变任一关键值。

预期：

- 审查模式高亮风险；
- 快速模式禁止写回。

## P0-14 正式文件不得新增承诺

原文没有交期保证。

模拟译文加入 “We guarantee delivery within 7 days.”

预期：

- 标记潜在新增承诺；
- 快速模式禁止应用。

## P0-15 术语库

验证：

- active 词条参与；
- draft 不参与强制；
- 同条件冲突 active 不允许保存；
- 最长短语优先；
- 目标语言不匹配时不强塞英语术语。

## P0-16 客户字段证据

输入中没有公司名，模型返回一个公司名且 evidence 不存在。

预期：

- 本地层拒绝 known；
- 不向用户显示成确定事实。

## P0-17 多产品不串值

输入同时包含产品 A 与 B，各自数量不同。

预期：

- 两个产品独立；
- 数量、材料、Logo 等不得串到另一产品。

## P0-18 条件缺项

输入：

“Please quote 5,000 pcs, including freight.”

但没有目的地。

预期：

- destination = missing / critical。

输入：

“Please quote product price only, freight excluded.”

预期：

- destination 不应作为关键缺项。

## P0-19 明确不适用

输入：

“No logo and no retail packaging.”

预期：

- Logo 与 packaging 相关字段为 not_applicable；
- 不生成“请提供 Logo 文件/包装设计”的追问。

## P0-20 模糊时间

输入：

“Need them before Christmas.”

预期：

- 保留原文；
- 标记具体日期需确认；
- 不自行补 2026-12-25；
- 不自动解释为工厂出货日。

## P0-21 OCR 本地性

操作：

1. 断开网络。
2. 使用已安装 OCR 语言截图。

预期：

- OCR 可本地完成；
- 不尝试上传截图。

## P0-22 OCR 语言缺失

选择系统未安装 OCR 能力的语言。

预期：

- 明确提示；
- 不自动下载大模型；
- 可以手动输入或选择已支持语言。

## P0-23 API key

验证：

- 配置文件中不可读取明文 API key；
- 日志中没有 key；
- 导出普通设置不包含 key。

## P0-24 默认无正文历史

完成翻译和客户整理后重启。

预期：

- 未显式另存的客户正文、译文、截图不从本地历史恢复。

## P0-25 被裁剪功能不启动

启动应用后验证：

- 无剪贴板持续监听；
- 无插件市场请求；
- 无云备份；
- 无更新轮询；
- 无 TTS/词典后台服务；
- 无业务 API 调用。

## 兼容性证据

交付前必须形成真实测试矩阵，至少覆盖：

- Windows 11；
- 常见浏览器可编辑文本；
- 常见原生文本框；
- VS Code；
- Word/Office 类编辑器至少记录支持等级。

等级：

- A：可安全快速覆盖；
- B：可审查后安全替换；
- C：只读/复制；
- Unsupported：明确不支持。

不得用“理论支持所有 Windows 软件”作为验收结论。
