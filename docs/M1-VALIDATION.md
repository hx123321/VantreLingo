# M1 翻译与受限写回验证

日期：2026-10-01。关联 [Issue #1](https://github.com/hx123321/VantreLingo/issues/1)。

## 实现范围

- `Alt+D` 永远只读；写作默认审查，设置可保存快速模式。
- 审查提供原文/可编辑译文、粗粒度文本 Diff、风险提示、替换、追加、复制、取消。
- 只有标准 Unicode Win32 `Edit` 能生成写回 Locator。密码、只读、禁用控件不提供 Locator；其他控件仍使用唯一 CaptureService 的 UI Automation 读取路径。
- Locator 包含原控件 HWND、UTF-16 选区偏移、完整控件文本的 SHA-256；正文及上下文不落盘，只有明确选区发送给 Provider。
- 写回两次验证进程、窗口、控件、原选区、选区原文、完整上下文和焦点，检查控件文本长度限制，然后通过一次 `EM_REPLACESEL` 提交完整文本。追加时提交“原选区 + 译文”，不先移动或删除选区。
- 快速模式只允许无风险的完整结果，不打开/激活工具窗口或目标窗口。失败使用托盘提示，结果留在内存供主动查看。
- 阅读、手动输入成功及确认写回成功时才允许提交最近外语。失败、取消、旧请求、无语言证据、有风险及未确认写回不提交。
- 发起新的操作、编辑原文、修改语言/设置、取消都会使旧请求失去 UI、复制、写回和语言记忆的所有权。
- 一旦向目标发送写入，即消费快照；即使超时或发送后无法确认，也禁止重复应用、自动重试、自动恢复。
- 除用户主动点击“复制译文”外，不读取、不改写剪贴板。没有 `Ctrl+A`、模拟粘贴、Enter、流式写回或焦点恢复路径。

## 自动检查

执行 `scripts/build.sh verify` 或 `scripts/Build.ps1 Verify`：锁定恢复、Release 构建、62 项 Core 检查。

检查覆盖请求取消/迟到隔离、语言路由和记忆、HTTP 完整结果/截断/超时、设置持久化，以及写回门控：阅读拒绝、目标身份变化、原文/上下文修改、相同文字不同选区、缺少 Locator、只读、范围异常、风险、无效译文、追加文本、取消后副作用禁止。

保护检查覆盖数字、单位、型号、代码、URL/邮箱/模板以及有限的新增承诺、否定和条件迹象；Diff 检查覆盖空字符串和 UTF-16 emoji。规则可能保守地阻止正确译文，不能证明语义等价，也不覆盖完整正式文件的责任主体/承诺强度要求；M2 已加入有限责任主体、义务强度和格式规则，仍不证明语义等价。

验证环境为 Debian 13 x64、.NET SDK 10.0.401，Windows x64 发布为交叉编译。HTTP 使用内存模拟响应，没有真实 Provider 凭据。自动检查验证 Core 决策，不验证 Windows API 的实际行为。

## Windows 实机验证待办

以下均为待执行步骤，不能作为已通过证据。需要 Windows 11 x64、.NET 10 Desktop Runtime、已配置的 Provider，以及允许延迟响应的测试 Provider。

1. 用确认为标准 Win32 `Edit` 的测试窗口选中文字，分别验证审查替换、追加、快速写回；记录应用版本、控件类型、选区与完整文本。现代 Notepad 不保证使用此控件。
2. 翻译等待期间切换到另一窗口或同窗口另一控件；确认没有任何应用被写入、没有抢焦点，快速失败只显示托盘提示（P0-06）。
3. 修改选区原文、只修改选区外的上下文、改选到另一处相同文字；三者均应阻止替换和追加（P0-07）。
4. 请求 A 延迟返回，先完成 B；确认 A 不显示、不复制、不写回、不修改最近外语。重复取消、关闭窗口和修改设置场景（P0-03/04）。
5. 在快速模式下按 `Alt+D`，确认仍只读且没有写回按钮。编辑审查译文，确认 Diff 和风险重新计算（P0-05）。
6. 模拟截断/空结果、数字/单位/型号/代码改变、新增明确承诺；快速保持原文，审查显示风险（P0-08/13/14 的部分规则）。
7. 验证长于控件最大容量的译文被发送前阻止；对无响应、关闭、权限不匹配的原窗口检查不会重试。发送后不确定时重新按应用按钮不得重复写入。
8. 翻译等待期间复制新的数据；完成后剪贴板仍保持新数据。检查从未模拟 `Ctrl+A`、粘贴或 Enter（P0-09/10）。
9. 连续输入并移动选区，检查跨进程读取/应用间的竞争。Win32 没有原子条件替换契约，两次验证不能证明不存在最后一次验证与 `EM_REPLACESEL` 之间的竞争；发现问题时不得给该控件 A/B 支持等级。
10. 验证首次中文→英文、日文/德文→中文后中文沿用最近外语，以及失败/取消/风险/未应用审查不更新外语记忆。重启后确认模式和有效外语可恢复且正文不恢复（P0-01/02/03/24）。
